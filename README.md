# RogueEvo
Turn-based RPG game with genetic algoritms(work in progress)
A 2D Roguelike with Turn-Based Combat and Genetic Algorithms

🎮 About the Project

Rogue Evo is a 2D roguelike game developed in Unity and C#, combining grid-based dungeon exploration, turn-based combat and evolutionary systems based on Genetic Algorithms.

The player explores successive dungeon levels, facing creatures with different characteristics and abilities. Each movement advances the game turn, allowing enemies to move and attack.

The project's main experimental feature is the use of Genetic Algorithms to generate and evolve enemy creatures. Their genetic information defines attributes such as health, damage, color and body characteristics, creating variations between individuals and generations.

The project is based on concepts and systems explored in Unity Learn's Create a 2D Roguelike Game course, which have been extended with an experimental evolutionary system.
